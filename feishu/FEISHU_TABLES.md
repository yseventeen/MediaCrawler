# 飞书多维表格列名说明

以下三张表对应配置中的 `FEISHU_BITABLE_TABLE_ID`（suggestions）、`FEISHU_BITABLE_TABLE_ID_COMMENTS`、`FEISHU_BITABLE_TABLE_ID_CONTENTS`。  
在飞书多维表格中创建表时，**列名需与下表完全一致**（均为文本字段）。

---

## 1. Suggestions 表（搜索建议 / 热词）

| 列名 |
|------|
| 日期 |
| 关键词 |
| 类型 |
| 内容 |
| 唯一键 |
| 元数据 |

- 唯一键：用于 upsert 去重（由 日期+关键词+类型+内容 生成）。
- 元数据：单条完整数据的 JSON 字符串。

---

## 2. Comments 表（评论）

| 列名 |
|------|
| 评论ID |
| 创建时间 |
| IP归属地 |
| 笔记ID |
| 评论内容 |
| 用户ID |
| 昵称 |
| 头像 |
| 子评论数 |
| 图片 |
| 父评论ID |
| 最后修改时间 |
| 点赞数 |
| 元数据 |

- 唯一键：**评论ID**（用于 upsert）。
- 元数据：单条完整评论的 JSON 字符串。

---

## 3. Contents 表（笔记/帖子）

| 列名 |
|------|
| 笔记ID |
| 类型 |
| 标题 |
| 描述 |
| 视频链接 |
| 发布时间 |
| 最后更新时间 |
| 用户ID |
| 昵称 |
| 头像 |
| 点赞数 |
| 收藏数 |
| 评论数 |
| 分享数 |
| IP归属地 |
| 图片列表 |
| 标签列表 |
| 最后修改时间戳 |
| 笔记链接 |
| 来源关键词 |
| 安全令牌 |
| 元数据 |

- 唯一键：**笔记ID**（用于 upsert）。
- 元数据：单条完整笔记的 JSON 字符串。
